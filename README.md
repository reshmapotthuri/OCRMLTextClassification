# OCRMLTextClassification
🚀 Image-to-Text Prediction with ML.NET: From Pixels to Insights 🧠📸
 Combining OCR and ML.NET multiclass classification:
🔍 OCR Pipeline
 Used Tesseract OCR via Emgu.CV to extract text from scanned images and documents. Cleaned and normalized the output for downstream ML tasks.
🧠 ML.NET Model
 Trained a MulticlassClassification model using SdcaMaximumEntropy to predict the intent or category of the extracted text. Ideal for document sorting, form understanding, and intelligent routing.
⚙️ Workflow Highlights
Preprocessing with Emgu.CV for image clarity
Text extraction with Tesseract
Label prediction using ML.NET
Integrated into a Razor dashboard for real-time feedback
